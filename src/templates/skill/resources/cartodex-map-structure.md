Every structural section heading must be followed by a `<!-- cartodex:paths ... -->` marker as the first non-blank content line. Use repo-relative literal paths only. A path ending in `/` covers a directory subtree; a path without a trailing `/` covers exactly that file. Do not use gitignore-style globs or wildcard semantics in markers for this version.
